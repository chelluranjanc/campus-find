# CampusFind

A university lost-and-found web application designed for RV University.

## Features
- **Browse Items**: Search and browse lost and found items across campus locations.
- **Report Items**: File reports for lost or found belongings with categories and details.
- **Responsive Interface**: Clean, accessible design optimized for both mobile and desktop.

## Running Locally
Open `index.html` directly in any web browser, or serve it locally using any static file server (e.g. `npx serve .` or `python3 -m http.server 8000`).
